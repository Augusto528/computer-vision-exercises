# Computer Vision Exercises

A collection of computer vision exercises and practical implementations developed collaboratively as part of an academic course.

## About

This repository contains practical assignments focused on computer vision, image processing, and computational methods.

The objective is to explore fundamental concepts, implement algorithms, and develop practical solutions using Python.

## Exercises

| Exercise | Description | Status |
|---|---|---|
| Exercise 01 | Rigid Body Motion and Perspective Projection Model | Completed |
| Exercise 02 | Homography Estimation | In progress |
| Exercise 03 | <W.I.P.> | In progress |

Each exercise is organized into its own directory, containing the source code, required resources, and documentation.

## Technologies

- Python
- NumPy
- OpenCV
- matplotlib

*Additional libraries may vary depending on the exercise.*
